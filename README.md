# Platz für Gute Ideen

Eine statische, fiktive Konzept-Demo für kleine Werbeflächen. Die enthaltene
Vorschau und die Preisbeispiele dienen nur der Illustration.

- Alle Beispielanzeigen und Preise sind als fiktive Demo bzw. unbestätigte
  Testannahmen gekennzeichnet.
- Es gibt keine echten Buchungen, Zahlungen, Reservierungen, Anzeigen-
  veröffentlichung oder Einnahmen.
- Das Formular sendet oder speichert keine Eingaben. Die Bildvorschau bleibt
  lokal im Browser.
- Keine Besucherzahlen, Reichweiten oder Kundenerfolge werden behauptet.

Öffentliche Vorschauseite: `site/index.html`.

## Dateien

- `site/index.html` – Webseite
- `site/styles.css` – responsive Gestaltung
- `site/booking-demo.js` – nur lokale, unverbindliche Vorschau
- `.github/workflows/pages.yml` – Bereitstellung über GitHub Pages

Die kostenlose Veröffentlichung auf GitHub Pages setzt ein öffentliches
GitHub-Repository und die jeweils geltenden GitHub-Bedingungen voraus. Eine
eigene Domain ist nicht konfiguriert.
